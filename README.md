# 《秦始皇——一统中国》阅读学习站

给一个在瑞典上四年级、母语中文的孩子做的中文阅读辅助材料。
配合《秦始皇——一统中国》（景崇兰 著，简志刚 绘，人民文学出版社「名人传」丛书）使用 ——
网站本身不含书的内容，
只有字词表、时间轴、人物关系和阅读指引。

**没有书也能看时间轴和人物关系；字词表和阅读指引要配合书一节一节读。**

## 网站结构

| 页面 | 作用 |
|---|---|
| `index.html` | 阅读指引 —— 六章十七节的进度表，每节链到字词表和读懂故事 |
| `vocab/` | 字词表，17 节 + 附录年表 + 全书合并 + ★重点 |
| `guide/` | 读懂故事 —— 带着问题读，填空梳理情节 |
| `characters.html` | 人物关系表 |
| `timeline.html` | 时间轴 |
| `fact-sheet.html` | 秦始皇小档案 |
| `reading-plan.html` | 阅读计划 |
| `how-to-use.html` | 怎么用这个站 |

字词表按五类标注：生字、★重点、词语、人名地名、只要会念。
每条给拼音和**给四年级孩子看的**解释，不抄词典。

## 本地打开

纯静态，没有构建步骤，双击 `index.html` 即可（`file://` 也能用）。

需要用手机或平板看：

```bash
python3 -m http.server 8000
# 然后访问 http://<这台机器的IP>:8000/
```

## 打印

每一页都做了 A4 打印样式：去掉导航、表头每页重复、单元格不跨页断开，
并留出写名字的一行。右上角有打印按钮。

## 代码结构

```
site.css      全站框架：页头、导航、页脚、基础排版、打印规则
vocab.css     字词表专用（和 site.css 零重叠）
site.js       唯一的脚本 —— 让「返回」按钮回到实际来源页
source/spec/  字词表的数据源，一节一个 JSON
vocab/*.html  由 spec 生成，不要手改
```

**`vocab/` 下的 HTML 是生成物**，由字词表技能的 `build_vocab_table.py`
从 `source/spec/*.json` 生成。要改字词表，改 spec 再重新生成。
其余页面是手写的。

**为什么 CSS/JS 放根目录、没有 `css/`、`js/` 子目录** —— 一共只有 3 个文件，
没有图片也没有字体。分目录要改 28 个页面里的 67 处引用，
而其中 21 个页面是生成的 —— 生成器的路径也得跟着改，否则下次重新生成
就会把 `../css/site.css` 写回 `../site.css`，所有字词表静默失去样式。
等到有 4 个以上样式表、或者开始放图片时再改成 `assets/{css,js,img}/`。

样式约定：框架用的 class 加 `site` / `sh-` / `nv-` 前缀，
避免和各页的短类名撞车。各页自己的内容样式留在那一页的 `<style>` 里 ——
因为 `.wrap.sheet` 被 26 个页面共用，把页面专有的规则提到 `site.css`
会漏到其他页面上。

## 出处

《秦始皇——一统中国》，景崇兰 著，简志刚 绘，人民文学出版社「名人传」丛书。
书的扫描页不在这个仓库里。
网站里的例句引自原书，用于辅助识字学习。
所有解释、题目、时间轴和人物关系表都是重新写的，不是书的内容。
