# 《秦始皇——一统中国》整本书阅读

给一个在瑞典上四年级、母语中文的孩子做的中文阅读辅助材料。
配合《秦始皇——一统中国》（景崇兰 著，简志刚 绘，人民文学出版社「名人传」丛书）使用 ——
网站本身不含书的内容，只有字词表、地图、时间轴、人物关系和阅读指引。

**没有书也能看地图、时间轴和人物关系；字词表和读懂故事要配合书一节一节读。**

**在线阅读**：https://learning-hub-ai.github.io/qinshihuang/

导航栏八个标签，顺序按「什么时候用」排：

## 本地打开

纯静态，双击 `index.html` 即可（`file://` 也能用）。

改页面内容不需要构建。只有改**全站共用的横幅／导航／页脚**时，
才改 `_frame/` 再跑一次 `python3 _build.py` —— 详见 `_frame/README.md`。

需要用手机或平板看：

```bash
python3 -m http.server 8000
# 然后访问 http://<这台机器的IP>:8000/
```

## 打印

每一页都做了 A4 打印样式：去掉导航、表头每页重复、单元格不跨页断开，
并留出写名字的一行。右上角有打印按钮。

## 代码结构

```
site.css       全站框架：页头、导航、页脚、基础排版、打印规则
vocab.css      字词表专用（和 site.css 零重叠）
site.js        唯一的脚本 —— 让「返回」按钮回到实际来源页
_frame/        全站共用的横幅／导航／页脚，只写一份
_build.py      把 _frame/ 写进每个页面（改框架后跑一次）
assets/maps/   地图图片
source/spec/   字词表的数据源，一节一个 JSON（不在仓库里）
vocab/*.html   由 spec 生成，不要手改
```

**`vocab/` 下的 HTML 是生成物**，由字词表技能的 `build_vocab_table.py`
从 `source/spec/*.json` 生成。要改字词表，改 spec 再重新生成。
其余页面是手写的。

**为什么 CSS/JS 放根目录、没有 `css/`、`js/` 子目录** —— 一共只有 3 个文件，
没有图片也没有字体。分目录要改 30 个页面里的引用，
而其中 21 个页面是生成的 —— 生成器的路径也得跟着改，否则下次重新生成
就会把 `../css/site.css` 写回 `../site.css`，所有字词表静默失去样式。
已经有了 `assets/maps/`；等样式表超过 4 个时再把 CSS/JS 也收进 `assets/`。

样式约定：框架用的 class 加 `site` / `sh-` / `nv-` 前缀，
避免和各页的短类名撞车。各页自己的内容样式留在那一页的 `<style>` 里 ——
因为 `.wrap.sheet` 被 30 个页面共用，把页面专有的规则提到 `site.css`
会漏到其他页面上。
